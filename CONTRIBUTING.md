# Contributing

This repository is a curated, published export of the MATH153 course material — it is not a general open-source project seeking contributions.

- **Bug reports welcome**: a broken link, a typo, a Lean example that no longer compiles against the pinned toolchain. Open an issue describing what's wrong and where.
- **Pull requests**: not accepted for course content (notes, slides, schedule). Content changes are made in the internal course source and republished. Small, unambiguous fixes to non-content files (e.g. a CI workflow typo) may be considered case by case.
- **This repository is not a coursework submission channel.** Do not open issues or pull requests to submit assignments, proofs, or exercises — follow the submission process described in class.
