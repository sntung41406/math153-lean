# `#eval`

**Meaning.** `#eval` runs a computable expression and prints its result.

**Example.**
```lean
#eval 2 + 2 -- 4
```

**Use it when** you want to see the actual value an expression computes to, not just its type.

**Reference.** [Lean 4 documentation — Environment](https://lean4.dev/language/foundations/environment)
