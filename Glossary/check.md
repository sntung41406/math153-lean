# `#check`

**Meaning.** `#check` reports an expression's type without evaluating it.

**Example.**
```lean
#check 2 + 2 -- 2 + 2 : Nat
```

**Use it when** you want to know what type an expression has, or confirm a definition elaborated the way you expect.

**Reference.** [Lean 4 documentation — Environment](https://lean4.dev/language/foundations/environment)
